# LLM RolePlay 项目功能文档

> 版本: v3.3.2
> 文档生成日期: 2026-04-19
> 视角: 用户操作流程
> 备注: CLI 模式自 v3.2.6 起已全面下线，系统仅支持 Web UI 模式

## 功能总览

从用户启动服务到退出，系统提供以下核心功能模块：

```
LLM RolePlay 角色扮演系统
│
├── 1. 🚀 服务启动
├── 2. 👤 角色管理
├── 3. 💬 对话管理
├── 4. 🤖 实时聊天
├── 5. ⚙️ 个人中心
├── 6. 📊 统计信息
├── 7. 🧠 记忆系统（后台自动运行）
└── 8. 🔒 服务退出
├── 9. 📚 知识库管理
```

## 1. 🚀 服务启动

### 1.1 Web 模式（推荐）
```
python main.py
```
- 启动 FastAPI 服务，监听 `localhost:8000`
- 浏览器访问 `http://localhost:8000` 进入 Web UI
- 启动时自动预加载 BAAI/bge-large-zh-v1.5 嵌入模型（约 1.5GB）

### 1.2 加载界面
- Web UI 启动时显示加载动画
- 进度条显示启动阶段：
  - 唤醒内核 → 加载模型列表 → 同步用户与角色信息 → 建立神经连接 → 就绪
- 加载完成后自动进入主界面

### 1.3 API Key 配置
- 首次运行时通过环境变量或 `data/credentials.json` 配置阿里云通义千问 API Key
- 支持 `DASHSCOPE_API_KEY` 或 `QWEN_API_KEY` 环境变量

## 2. 👤 角色管理

### 2.1 创建新角色
```
左侧边栏 → [+ 新建角色]
```
- **必填项**：角色名称
- **可选项**：
  - 角色设定（System Prompt）— 定义角色性格、语气、背景
  - 头像上传（可选，支持裁剪工具）
  - 高级参数设置（已填入系统推荐值）：
    - Temperature（默认 1.0）
    - Top P（默认 0.8）
    - Top K（默认 20）
    - 重复惩罚（默认 1.1）
    - 新鲜度惩罚（默认 0.0）
    - 思维链上限（默认 81920）

### 2.2 角色列表
- 左侧边栏显示所有已创建角色
- 显示角色名称和头像
- 头像显示模式：
  - 经典圆形（1:1 比例）
  - 卡片渐变背景（4:1 比例）— 侧边栏隐藏头像显示
- 当前选中角色高亮标识

### 2.3 角色设置
```
选择角色后 → 顶部 [角色设置] 按钮
```
- **基础设置**：
  - 角色名称（显示名）
  - 头像显示模式（经典圆形 / 卡片渐变背景）
  - 角色设定（System Prompt）
  - 头像预览与更换（点击打开裁剪工具）
- **高级大模型参数**：
  - Temperature
  - Top P
  - Top K
  - 重复惩罚
  - 新鲜度惩罚
  - 思维链上限
- 修改后点击 [保存角色配置] 即时生效

### 2.4 删除角色
```
左侧边栏 → [删除角色] 按钮 → 进入删除模式 → 点击目标角色
```
- **两步确认机制**：
  - 第一步：确认删除角色 xxx？
  - 第二步：确认删除角色 xxx，ta 已经陪伴你 nnn 天了？
- 删除时显示角色的陪伴天数
- 删除后自动退出删除模式
- 删除操作不可逆

### 2.5 头像上传与裁剪
- 支持图片文件上传（PNG、JPG 等）
- 内置裁剪工具，支持：
  - 第一步：1:1 比例裁剪圆形头像
  - 第二步：4:1 比例裁剪渐变背景图
- 裁剪时支持鼠标拖拽调整位置、滚轮缩放
- 裁剪后自动上传并实时刷新预览

## 3. 💬 对话管理

### 3.1 创建新对话
```
侧边栏对话列表 → [+ 新建对话]
```
- 自动命名"对话N"（N 为序号）
- 创建后自动切换到新对话

### 3.2 切换对话
- 侧边栏对话列表显示所有历史对话
- 点击对话卡片切换上下文
- 显示对话最后更新时间
- 当前选中对话高亮标识

### 3.3 重命名对话
```
顶部 [对话设置] 按钮 → 输入新名称 → [保存]
```

### 3.4 删除对话
```
[对话设置] → [删除对话] → 确认弹窗
```
- 删除确认提示：此操作不可逆，仅删除该对话的上下文，不会影响记忆数据库
- 删除后自动切换到下一个对话
- 若所有对话都被删除，自动创建新对话

### 3.5 对话历史查看
- 切换对话时自动加载历史聊天记录
- 历史消息支持 Markdown 渲染
- 历史消息显示使用的模型和 Token 用量
- 历史消息中显示上传的图片
- 历史与当前对话以分隔线区分（--- 历史记忆 ---）

## 4. 🤖 实时聊天

### 4.1 消息发送
- 文本输入框支持单行输入，Enter 键发送消息
- **输入框气泡模式**（内容超出一行时可用）：
  - 输入内容超出一行时，输入框上方显示"展开"按钮（带下箭头的小圆圈）
  - 点击展开按钮 → 在输入框上方弹出气泡，以多行方式完整显示输入内容
  - 气泡顶部显示"收起"按钮（带上箭头的小圆圈），点击可收回气泡
  - 气泡模式下原输入框边框高亮，表示当前使用气泡模式
  - 气泡最大高度为屏幕高度的 1/3，超出后内部出现滚动条
  - 气泡模式与原输入框内容双向实时同步，切换模式不丢失内容
  - 气泡模式下仍可正常发送消息（Enter 键或点击发送按钮）
  - 以气泡模式发送内容后，气泡自动收回，恢复原输入框状态
- [发送] 按钮发送
- 生成中时输入框锁定

### 4.2 图片上传（多模态）
```
输入框左侧 [+] 按钮 → 选择图片
```
- 支持多张图片上传
- 上传前可预览和删除
- 图片自动保存到角色的 images 文件夹
- 仅当所选模型支持多模态时可用（自动检测）

### 4.3 模型选择
```
输入框右侧下拉菜单
```
- 可选模型：
  | 模型 | 描述 | 多模态 | 深度思考 | 联网搜索 | 上下文窗口 |
  |------|------|--------|----------|----------|------------|
  | Qwen3-Max | 旗舰版，集成Web搜索、网页信息提取和代码解释器三项工具 | ✅ | ✅ | ✅ | 262,144 |
  | Qwen3.6-Plus | Plus系列最新模型，支持深度思考和多模态理解 | ✅ | ✅ | ✅ | 1,000,000 |
  | Qwen3.5-Plus | 增强版，支持深度思考和多模态理解，平衡性能与效果 | ✅ | ✅ | ✅ | 1,000,000 |
  | Qwen3.5-Flash | 轻量版，快速响应，适合实时对话和简单任务 | ✅ | ✅ | ✅ | 1,000,000 |
  | Qwen3-VL-Plus | 视觉语言增强版，专注于图像理解与生成 | ✅ | ✅ | ❌ | 262,144 |
  | Qwen3-VL-Flash | 视觉语言轻量版，快速图像处理 | ✅ | ❌ | ❌ | 262,144 |
  | Qwen3.5-397B-A17B | 超大规模模型，397B总参数，A17B激活参数，超强性能 | ✅ | ✅ | ❌ | 262,144 |
- 每个模型展示名称、描述、上下文窗口大小、是否支持思考和联网搜索
- 支持查看模型详细信息（悬浮弹窗），包括特性支持列表
- 自动记忆用户首选模型

### 4.4 深度思考
```
[深度思考: 关/开] 按钮
```
- 切换模型的思考模式（enable_think）
- 开启后 AI 回复显示思考过程（可折叠展开）
- 思考过程以 Markdown 渲染
- 设置按角色保存

### 4.5 联网搜索
```
[联网搜索: 关/开] 按钮
```
- 切换模型的联网搜索功能（enable_search）
- 仅当前选中的模型支持时可用（自动灰显禁用）
- 部分模型（如 VL 系列、397B）不支持此功能

### 4.6 深度回忆模式
```
[深度回忆: 关/正常/增强] 按钮 — 循环切换
```
- **关闭**：不进行深度回忆，仅使用短期记忆
- **正常**：从分层总结库（日/周/月/年）检索记忆
- **增强**：从最近半年的原始记录库检索记忆
- 按角色保存设置
- 自动意图检测：输入包含"你还记得...吗"、"仔细回忆"、"很久以前"等关键词时自动触发

### 4.7 流式响应
- WebSocket 实时推送
- 打字机效果逐字显示
- Markdown 渲染支持
- 代码语法高亮（Highlight.js）
- Token 用量实时显示：
  - 输入 Token 数量
  - 输出 Token 数量
  - 缓存命中 Token 数量
  - 总计 Token 数量
- 使用模型名称显示

### 4.8 连接状态
- 连接状态指示灯：
  - 绿色 — 已连接
  - 红色 — 断开
- 断线自动重连（指数退避策略，2s~30s）
- 总结状态指示："总结上下文中..."

## 7. 🧠 记忆系统（后台自动运行）

### 7.1 四级分层记忆架构
```
记忆层级结构：
│
├── L0 工作记忆 — 实时滑动窗口（当前对话上下文）
├── L1 日级总结 — 每日对话压缩总结（保留 14 天）
├── L2 周级总结 — 每周对话总结（保留 8 周）
├── L3 月级总结 — 每月对话总结（保留 12 个月）
└── L4 年级总结 — 每年对话总结（保留 100 年）
```

### 7.2 自动记忆压缩触发条件
- **闲置触发**：用户闲置时间 ≥ 15 分钟
- **时间边界触发**：跨越日期边界后等待 ≥ 30 分钟
- **记忆年龄触发**：存在超过 4 小时未总结的记忆

### 7.3 总结生成
- 使用 Qwen3.5-Flash 模型，开启思考模式
- 思考预算：4096 tokens
- 各层级专用 Prompt 模板：
  | 层级 | 要求 | 字数 |
  |------|------|------|
  | 日级 | 突出重要事件和情感变化 | 200-400 字 |
  | 周级 | 提炼核心主题和重要发展 | 300-500 字 |
  | 月级 | 提炼核心事件和成长变化 | 400-600 字 |
  | 年级 | 提炼核心主题和重大变化 | 500-800 字 |
- **回退机制**：LLM 失败时自动使用关键词提取算法

### 7.4 深度回忆检索
- **正常模式**：
  - 从 L1~L4 总结库进行语义向量检索
  - 根据时间范围智能选择检索来源
  - 检索结果标注时间标签（如 [数日前的模糊回忆]）
- **增强模式**：
  - 从最近 6 个月的原始记录库检索
  - 提供精确的细节回忆
  - 检索结果标注 [仔细回想起来的清晰回忆]
- **跨对话检索**：
  - 在所有对话的上下文中搜索未总结和已存档的消息
  - 使用关键词匹配
  - 检索结果标注 [跨对话回忆]

### 7.5 向量数据库
- 使用 ChromaDB 作为向量数据库
- 嵌入模型：BAAI/bge-large-zh-v1.5
- 按时间分区存储（日/周/月/年/半年）
- 支持语义相似度检索

### 7.6 服务启动/关闭时的记忆处理
- **启动时**：检查并总结未总结的记录到 L1 日级记忆库
- **关闭时**：
  - 总结所有未总结的记录
  - 存档所有未记录到向量库的数据
  - 执行层级递进压缩（日→周→月→年）

## 8. 🔒 服务退出

### 8.1 安全退出
```
个人中心 → [退出服务] → 确认
```

### 8.2 退出前处理
- 触发所有会话的关闭操作
- 执行记忆凝固整理：
  - 总结未归档的记忆
  - 存档未记录的对话到原始数据库
- 所有数据库连接正常关闭，释放文件锁定
- 3 秒后程序自动退出

### 8.3 数据安全保障
- 所有角色数据持久化到 `data/roles/` 目录
- 统计数据持久化到 `data/stats/` 目录
- 用户配置持久化到 `data/user_meta.json`
- 头像文件存储在 `data/avatars/`

## 9. 📚 知识库管理

### 9.1 概述
知识库功能允许用户上传和管理文档资料，系统会自动解析文档内容并在对话时提供参考。每个知识库可包含多个文档，支持 DOCX、XLSX、PDF 三种格式。

### 9.2 创建知识库
```
侧边栏 → [知识库] 折叠面板 → [+ 新建知识库]
```
- **必填项**：知识库名称
- **可选项**：知识库描述
- 创建成功后自动刷新侧边栏知识库列表

### 9.3 删除知识库
```
知识库列表 → [删除知识库] 按钮 → 应用内确认弹窗
```
- 确认弹窗提示：将同时删除该知识库下的所有文档，且无法恢复
- 删除成功后自动刷新知识库列表

### 9.4 上传文档
```
选择知识库 → [上传文档] 按钮 → 选择文件
```
- 支持格式：DOCX、XLSX、PDF
- 上传后自动解析文档内容（标题、段落、表格）
- 解析完成后自动刷新文档列表

### 9.5 文档列表
- 显示文档类型标签（DOC / XLS / PDF）、文件名、文件大小、上传时间
- 每个文档提供「预览」和「删除」两个操作按钮
- 预览按钮打开文档选择器并加载该文档内容
- 删除按钮弹出应用内确认弹窗，确认后才执行删除

### 9.6 文档选择器
```
[知识库文档] 菜单项 或 文档列表中的 [预览] 按钮
```
- **双栏布局**：
  - 左侧：知识库标签页 + 文档列表（宽度 200px）
  - 右侧：文档预览区（占剩余空间，至少 4/5 宽度）
- **预览功能**：
  - 自动渲染解析后的文档内容（标题、段落、表格）
  - 预览工具栏显示当前文档名称
  - 支持全屏预览模式（点击「全屏」按钮）
- **文本选择引用**：
  - 在预览区选中文字后，底部显示选中字符数
  - 点击「确认引用」可将选中文本插入到对话输入框
  - 点击「清除选择」取消当前选区
- 全屏模式下点击「退出全屏」或遮罩层恢复正常大小

### 9.7 侧边栏知识库面板
- 通过折叠面板（Accordion）组织，与角色列表并列
- 展开知识库面板时自动加载已有知识库列表
- 知识库以卡片形式展示：名称左对齐、文档数量右对齐
- 底部固定「+ 新建知识库」按钮
